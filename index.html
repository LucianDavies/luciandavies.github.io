Functional Core, Imperative Shell Makes Sense for Micro Apps

Tonderai Khatai  published on 2026-04-15 included in Projects

Functional core, imperative shell usually gets pitched as a full architecture: pure domain functions in one layer, all I/O pushed to the edges, everything wired together through explicit ports. Kacper Antman’s Functional Domain-Driven Design, Simplified is a good, concrete version of that pitch — it adapts DDD’s tactical patterns (aggregates, services, value objects) for a functional style: derivers as pure functions that take all their inputs explicitly and return a discriminated union of outcomes, controllers as the imperative code that orchestrates databases and external services around those derivers, and invariants as small pure predicates that check one business rule each.
